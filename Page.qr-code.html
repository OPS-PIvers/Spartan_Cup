How to Use

  1. Display or print this QR code at your event location
  2. Students scan the code with their phone camera
  3. The app automatically detects their location and selects the closest event
  4. They take a photo and submit
  5. The system validates their location and time window automatically

Note: This is a single, reusable QR code. You can print it once and use it for all events. The event selection happens dynamically based on the student's location and the active event time window.
