Print This QR Code

Display or print this QR code at your events. Students scan it to submit attendance.

How to Use

  1. Display or print this QR code at your event location
  2. Students scan the code with their phone camera
  3. The geolocation wrapper requests location permission (works on iOS Safari! ✅)
  4. App automatically detects their location and selects the closest event
  5. They take a photo and submit
  6. The system validates their location and time window automatically

ℹ️ Info: This QR code links to the Firebase geolocation wrapper at https://the-spartan-cup.web.app, which captures location permission before loading the app.
